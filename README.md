# 📝 유튜브 스크립트 추출기

유튜브 주소를 붙여넣으면 영상의 자막(스크립트)을 텍스트로 정리해 주는 간단한 사이트입니다.
캡처할 필요 없이 **전체 복사** 버튼 한 번으로 Claude에 붙여넣을 수 있어요.

## 기능
- 유튜브 주소 붙여넣기 → 자동으로 스크립트 불러오기 (`watch?v=`, `youtu.be`, `shorts`, `live` 주소 지원)
- 자막 언어 선택 (한국어 자막이 있으면 우선 선택, 자동 생성 자막도 지원)
- 타임스탬프 포함/제외, 문단 자동 나누기
- "제목·안내문 포함" 옵션: 맨 앞에 영상 제목과 주소를 붙여서 Claude가 맥락을 알 수 있게 함
- 📋 전체 복사 / 💾 .txt 파일 저장, 글자 수 표시

## 인터넷에 올리기 (무료, 약 3분) — Vercel
1. https://vercel.com 에 GitHub 계정으로 로그인
2. **Add New → Project** → 이 저장소(`dailytarot`) **Import**
3. 설정은 건드리지 말고 **Deploy** 클릭
4. 생성된 주소(예: `https://dailytarot-xxx.vercel.app`)를 휴대폰 홈 화면에 추가해서 사용

## 내 컴퓨터에서 실행
Node.js 18 이상이 필요합니다.
```bash
node server.js
```
→ 브라우저에서 http://localhost:3000 열기

## 파일 구성
- `public/index.html` — 화면
- `api/transcript.js` — 유튜브에서 자막을 가져오는 서버 함수 (브라우저에서는 보안 정책(CORS) 때문에 직접 가져올 수 없어서 필요)
- `server.js` — 내 컴퓨터에서 실행할 때 쓰는 서버

## 참고
- 자막이 아예 없는 영상은 가져올 수 없습니다.
- 유튜브가 가끔 서버 요청을 봇으로 판단해 막을 수 있습니다. 그럴 땐 잠시 후 다시 시도하거나 내 컴퓨터에서 `node server.js`로 실행하면 대부분 해결됩니다.
